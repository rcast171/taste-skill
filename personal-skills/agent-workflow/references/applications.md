# Agent applications and output shapes

Use these source-grounded course examples to adapt the context and output to the bounded task. Preserve the core chronological workflow. Select relevant, authorized, available sources; ask only for essential gaps. Do not assume all listed systems are connected.

| Area | Agent example | Job | Relevant approved context |
|---|---|---|---|
| Sales | Account Brief Agent | Prepare a consistent brief before customer meetings or pipeline reviews | CRM records, account notes, recent emails, meeting history, product information, customer-success updates |
| Marketing | Launch Review Agent | Gather launch status, blockers, campaign changes, and approval needs | Campaign plans, creative briefs, project trackers, performance dashboards, launch calendars, team messages |
| Business operations | Weekly Operations Review Agent | Bring together operational metrics, escalations, blockers, and priority decisions | SLA reports, process documentation, escalation logs, task trackers, team updates |
| Legal | Legal Intake Agent | Organize incoming review requests for triage without providing final legal advice | Intake forms, contract trackers, policy documents, matter records, request emails |
| Communications | Communications Review Agent | Prepare a review packet for announcements, executive communications, or stakeholder updates | Message drafts, communication plans, audience guidance, brand standards, media notes, prior feedback |
| Finance | Variance Review Agent | Prepare a financial review explaining changes without inventing causes | Budget sheets, actuals reports, forecast notes, approval records, prior variance summaries |
| Data science | Experiment Review Agent | Prepare a review packet for experiments, analyses, and next-step decisions | Experiment logs, analysis notebooks, metric definitions, result tables, research notes, prior reviews |
| Technical engineering | Release Readiness Agent | Prepare a release review from shipped work, open risks, incidents, tests, and deployment status | Issue trackers, pull-request summaries, test results, deployment notes, incident reports, release criteria |
